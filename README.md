🎯 ¿QUÉ ES ESTE SCRIPT?
Este es un script automatizado para el juego Blox Fruits en Roblox que te permite farmear niveles, recolectar items y derrotar enemigos automáticamente.

✨ CARACTERÍSTICAS PRINCIPALES
Función	Descripción	Estado
🎯 Auto Farm	Farmea enemigos automáticamente	✅ Activado
🍎 Auto Collect Fruits	Recolecta frutas cercanas	✅ Activado
📦 Auto Collect Chests	Abre cofres automáticamente	✅ Activado
💀 Auto Collect Bones	Recolecta huesos	✅ Activado
👹 Auto Kill Boss	Derrota jefes automáticamente	✅ Activado
🌊 Auto Sea Beast	Caza bestias marinas	❌ Desactivado
🏛️ Auto Raid	Participa en raids	❌ Desactivado
🛒 Auto Buy	Compras automáticas	✅ Activado
📊 Auto Stats	Mejora estadísticas	✅ Activado
📋 REQUISITOS
Necesario:
✅ Tener Roblox instalado

✅ Tener Blox Fruits abierto

✅ Tener un ejecutor de scripts (Synapse, KRNL, Fluxus, etc.)

✅ Conexión a Internet estable

Recomendado:
✅ Nivel mínimo 100+ para mejor eficiencia

✅ Fruta tipo Buddha o Light para farmeo rápido

✅ PC con buen rendimiento

🚀 CÓMO USAR EL SCRIPT
PASO 1: Preparación
Abre Roblox y entra a Blox Fruits

Espera a que cargue completamente tu personaje

Abre tu ejecutor de scripts

PASO 2: Copiar el Script
Copia TODO el código del script (Ctrl+C)

Pégalo en tu ejecutor (Ctrl+V)

Presiona "Execute" o "Ejecutar"

PASO 3: Controlar el Script
Una vez ejecutado, puedes usar estos comandos:

text
commands.start()     - Iniciar el Auto Farm
commands.stop()      - Detener el Auto Farm  
commands.status()    - Ver estado actual
commands.setlevel(1000) - Cambiar nivel objetivo
commands.help()      - Mostrar ayuda
⚙️ CONFIGURACIÓN PERSONALIZADA
Puedes modificar estas opciones ANTES de ejecutar el script:

lua
local config = {
    -- Activar/Desactivar funciones
    AutoFarm = true,              -- true = activado, false = desactivado
    AutoCollectFruits = true,     
    AutoCollectBones = true,
    AutoCollectChests = true,
    AutoKillBoss = true,
    AutoBuy = true,
    
    -- Distancias (en metros)
    DistanceToFarm = 500,         -- Distancia para farmear
    DistanceToCollect = 300,      -- Distancia para recolectar
    DistanceToBoss = 400,         -- Distancia para jefes
    
    -- Tiempos (en segundos)
    WaitTime = 0.1,               -- Tiempo entre acciones
    TeleportDelay = 0.5,          -- Retraso al moverse
    
    -- Frutas preferidas
    PreferredFruits = {"Buddha", "Light", "Flame", "Dough", "Venom"},
    
    -- Nivel objetivo
    TargetLevel = 2550,           -- Nivel máximo del juego
}

🔧 SOLUCIÓN DE PROBLEMAS
❌ El script no funciona
Solución:

Verifica que estás en Blox Fruits

Asegúrate que tu ejecutor esté actualizado

Revisa la consola de errores

❌ No encuentra enemigos
Solución:

Ve a una zona con enemigos (Jungla, Ciudad, etc.)

Aumenta la DistanceToFarm en la configuración

Verifica que no estés en modo seguro

❌ El personaje no se mueve
Solución:

Verifica que no estés muerto

Asegúrate de tener el personaje cargado

Reinicia el script

❌ Error de ejecución
Solución:

Copia el script nuevamente

Asegúrate de copiar TODO el código

Prueba con otro ejecutor
